## Installation and Usage

**Note: Works Better without glasses**

**Linux**

```bash
python3 -m venv env
source env/bin/activate
pip install -r requirements.txt
python3 main.py
```

**Windows**

```bat
python3 -m venv env
cd env/Scripts
activate
cd ../../
python3 main.py
```
